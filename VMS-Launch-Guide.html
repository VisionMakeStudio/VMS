Netlify deployment

1
Create or choose your Netlify project.

Upload this entire folder or connect it to GitHub. Do not upload only index.html; the Admin, Portal, assets and Functions folders are required.

2
Connect your GoDaddy domain.

In Netlify, add visionmakestudio.com as the custom domain. Netlify will show the DNS records to add at GoDaddy. Keep Google Workspace MX records unchanged.

3
Create Supabase project and run the schema.

Open Supabase SQL Editor and run supabase/schema.sql. Copy Project URL + anon key into assets/config.js. Put the service-role key only in Netlify environment variables, never in browser code.

4
Create your Admin user.

Sign in once with the owner email you want to use. Then run the final commented SQL line in schema.sql using that email to give the user the admin role. Your Admin URL is /admin/login.html.

5
Add environment variables in Netlify.

OPENAI_API_KEY, OPENAI_AUDIT_MODEL=gpt-5.6-luna, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY. Optional email notifications: RESEND_API_KEY, VMS_NOTIFICATION_FROM, and VMS_INTERNAL_NOTIFY_TOKEN.

6
Test.

Public form → Admin request; Member Portal magic link; Admin login; AI Audit Run/Re-run; mobile layouts; buttons/links; then publish.

AI Audit

The browser never receives your OpenAI key. /api/ai-audit is a Netlify serverless function and reads OPENAI_API_KEY from Netlify. The Audit Assistant sends the business details + exact VMS rubric, receives structured category scores/reasons/selections, and still requires you to accept/edit the suggestions before they become final.

Cheaper hosting alternative

Cloudflare Pages can host static assets for $0 and static asset requests are free/unlimited. Its Functions run on Workers quotas. You can keep Supabase + OpenAI the same, but the included serverless functions are already written for Netlify, so Netlify is the easiest launch path for this package.
